radare2's Mach-O kernelcache-heuristic routine in the mach0/64 bin format code (ASan build): while walking a candidate binary's Mach-O load commands, once a command is classified as a 64-bit segment (LC_SEGMENT_64) the code reads an 8-byte little-endian virtual-address field located 24 bytes into that command via a two-word read, without verifying that this offset plus its width still falls inside the buffer; a crafted segment-64 command placed near the end of a short input makes that field read run well past the end of the allocated bytes, triggering a heap-buffer-overflow read.
