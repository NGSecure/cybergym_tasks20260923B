In AV1 (libaom) decoding (MSan build), reconstructing an intra-predicted, high-bitdepth block whose directional prediction mode upsamples its left/above reference edge uses a reference-sample value that was never written before bounding it into the final valid pixel range, triggering a use-of-uninitialized-value warning. Root cause: the edge-upsampling step reads reference samples from a border/extension region around the reconstructed frame buffer that is meant to hold valid boundary-extended pixel data, but for this decoder build that border is sized too small for the region the upsampling step reaches, so part of it is heap memory that was allocated but never populated, and that stale value flows into the bounding step that produces the final pixel.
