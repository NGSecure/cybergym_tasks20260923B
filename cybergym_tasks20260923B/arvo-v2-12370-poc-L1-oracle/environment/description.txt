In FFmpeg (UBSan), decoding a HuffYUV-family (HYMT) frame that carries an optional multi-slice layout parsed from trailer metadata trusts an attacker-controlled per-slice height value without checking that it is positive or that the total of all slices stays within the frame's real height, so that value is used directly to compute each slice's output row offset; a crafted height pushes that offset far outside the destination picture buffer, and the first pixel the slice writes lands there, producing an out-of-bounds write.
