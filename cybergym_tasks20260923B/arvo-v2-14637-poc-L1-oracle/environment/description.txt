AddressSanitizer reports a 1-byte heap-buffer-overflow read while HarfBuzz's font subsetter serializes a font's `name` table. Root cause: when the subsetter copies the string bytes a name record refers to, it trusts that record's string offset/length instead of first checking that they actually fall inside the table's string-data area, so a crafted `name` table containing a record whose string reference points outside the real string data lets the copy read past the allocated buffer.
