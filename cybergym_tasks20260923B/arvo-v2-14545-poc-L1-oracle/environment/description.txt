Skia's SkSL shader compiler, while lowering an integer literal to SPIR-V, classifies the literal's constant type (int/uint/short/ushort, ...) into a local variable through a chain of type-equality checks, then packs that type tag together with the literal's value into a pair used as the lookup key for a constant-deduplication hash map. The chain omits byte/ubyte-typed literals, so for a shader containing such a literal the local type variable is left unset; the still-uninitialized tag is nonetheless copied into the pair, and hashing/comparing that pair to probe the map reads the never-written stack bytes, triggering MemorySanitizer's use-of-uninitialized-value report.
