kimageformats' GIMP XCF image loader fuzz target (MSan build): a crafted XCF layer whose compressed tile data has a zero/invalid offset is treated as a "broken but recoverable" case, and the loader blanks out only the layer's main color tile to a defined value while leaving the layer's separate alpha-channel tile (present for grayscale-with-alpha and indexed-with-alpha layers) as freshly heap-allocated, never-written memory. When that layer is later composited into the final image, the per-pixel alpha value is read straight back out of this never-initialized tile and used to decide, via a conditional branch, whether the pixel has anything to merge at all — so the branch itself is taken on uninitialized data, which MemorySanitizer flags as a use-of-uninitialized-value.
