ReadStat parsing an SPSS .sav "long string missing values" record reads each variable's Pascal-encoded name and then unconditionally consumes one more byte as the missing-value count without first checking that any bytes remain in the record; when the variable-name field happens to run exactly to the end of the record buffer, that count byte is read one byte past the heap-allocated record buffer, producing a 1-byte out-of-bounds heap read.
