In radare2 (ASan wild-address read/SIGSEGV), parsing a DEX class's field/method-count header inside its class-data section decodes a variable-length integer from a region whose end-of-buffer pointer is computed by subtracting a header-supplied class-data offset from the total file size without first checking that the offset does not exceed that size, so a crafted offset larger than the file makes the unsigned subtraction underflow to a huge bogus length, effectively removing the bound and letting the decoder start reading from a pointer already past the end of the mapped file.
