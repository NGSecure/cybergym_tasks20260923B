ImageMagick's DNG (raw-camera image) reader (ping fuzz target, UBSan build) hands a crafted file to its bundled raw-decoder library for format identification. Root cause: while scanning the file's set of embedded TIFF sub-images to decide which one represents the actual sensor data, the decoder tracks the best candidate found so far in an index variable that starts out set to a "nothing selected yet" sentinel and is only overwritten once a sub-image satisfies a set of selection criteria (compression mode, sample count, bit depth, dimensions, and tie-breaking rules). A malformed file can be shaped so that every embedded sub-image fails those criteria, leaving the sentinel value untouched. A later code path that special-cases raw files produced by a certain camera vendor's transfer utility then unconditionally uses that same index to look up the selected sub-image's parsed metadata inside a small, fixed-size table of per-sub-image descriptors, without first verifying that a valid candidate was ever actually chosen, so the untouched sentinel is used directly as a negative, out-of-bounds array index.
