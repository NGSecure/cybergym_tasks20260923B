Disassembling a PowerPC TBEGIN instruction reaches the disassembler's unsigned-integer print helper with an uninitialized value. Root cause: the generated PowerPC asm-writer's operand-print dispatch groups TBEGIN together with other instructions that print a second immediate operand and dumps MCInst operand index 1 for it, but the instruction decoder only ever populates operand index 0 for TBEGIN, so the immediate-printing helper reads and formats an unset stack slot from the disassembler's per-call MCInst instead of an actual decoded value.
