A pattern that enables the ECMAScript-style alternate `\u` escape syntax and ends immediately after a bare `\u` triggers a 1-byte heap-buffer-overflow read during compilation. Root cause: to decide whether the escape is the `\u{hex...}` form or the plain 4-hex-digit form, the parser peeks at the byte the input cursor currently points to without first checking that the cursor is still within the pattern buffer, so when `\u` is the very last content in the pattern the peek reads one byte past the end of the allocation.
