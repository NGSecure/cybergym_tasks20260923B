open62541's JSON decoder converts a ByteString field's base64 text using a legacy decode routine that derives the output buffer's byte count solely from whether the last one or two characters are padding ('='), without verifying that the input length is actually a multiple of four; for a malformed, non-multiple-of-four base64 token this mis-sized allocation ends up smaller than what the routine's trailing-group branch subsequently writes, causing a heap-buffer-overflow write during decoding.
