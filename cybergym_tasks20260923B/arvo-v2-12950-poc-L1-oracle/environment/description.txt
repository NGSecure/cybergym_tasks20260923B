When PCRE2 compiles a UTF-8 pattern, the routine that validates each character of a named capturing group's name advances the input pointer one byte past the last accepted identifier character and immediately probes that new pointer position to decode the next UTF-8 code point, checking only afterward whether the pointer has run past the end of the pattern buffer. If the last accepted identifier character sits at the very end of the pattern, that multi-byte decode step reads one byte beyond the heap-allocated pattern buffer before the end-of-buffer check has a chance to stop it.
