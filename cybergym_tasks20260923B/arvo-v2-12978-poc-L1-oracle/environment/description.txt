On the second parse pass over a SAS7BDAT data page, ReadStat validates that a subheader entry's declared offset and length fit within the page's allocated buffer, but never checks that the length is at least as large as the fixed-width signature value it is about to read from that offset. A subheader placed near the tail of the page with a length shorter than the signature width passes the offset/length check yet causes the subsequent fixed-width little-endian integer read to run past the end of the page's heap allocation, producing a heap-buffer-overflow read.
