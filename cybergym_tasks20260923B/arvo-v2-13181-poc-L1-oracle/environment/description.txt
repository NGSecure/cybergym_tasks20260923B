ImageMagick (ASan build): reading a crafted DNG (Digital Negative) raw-photo file through ImageMagick's DNG coder, which hands the pixel data off to the bundled LibRaw raw-image decoding library, triggers a global-buffer-overflow read. While parsing a Pentax-camera maker-note block that lists per-shot white-balance color coefficients, the decoder loops over a small fixed-size lookup table, reading one byte per iteration from the file to pick which table entry to use next. If the file runs out of data partway through this loop, the per-byte read returns its usual end-of-stream sentinel value rather than a valid byte, and that sentinel is a negative integer. The bounds check guarding the table lookup only rejects an index that is too large (at or past the end of the table); it never rejects a negative one, so a truncated maker-note block drives the index below the start of the table instead of failing the read, and the lookup walks backward into whatever global data sits immediately before the table in memory — the resulting out-of-bounds read lands a few bytes before the table rather than inside a valid entry.
