ReadStat's SPSS (.sav) variable-record parser (ASan bad-free / heap corruption): a variable's file-supplied missing-value count is a raw signed 32-bit integer that the code sign-normalizes with abs() before bounding it and using it as the length of a read into a fixed 3-slot on-struct buffer; because abs() of the most-negative int wraps back to a negative value instead of a large positive one, that specific count slips past the upper-bound check, so the subsequent length-controlled read overflows the small buffer and corrupts the containing struct's own later fields with attacker-controlled bytes, which only surfaces later as an allocator crash when one of those corrupted fields is freed.
