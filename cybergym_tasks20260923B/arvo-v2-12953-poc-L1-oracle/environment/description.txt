In Capstone's TMS320C64x architecture module, the lookup function that converts a recognized instruction id into a readable mnemonic string indexes a static lookup table directly by that id. The table was only hand-populated with a handful of mappings, far fewer entries than the total range of instruction ids the architecture defines, so most valid instruction ids index past the end of the table when looked up, reading into adjacent global data and producing a global-buffer-overflow read.
